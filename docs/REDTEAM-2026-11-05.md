# Red team, 2026-11-05

Two reviewers read `page/overseer.html` end to end, one for security and data trust, one for
correctness and usability. Each finding was checked against the code and, where possible,
reproduced with `tools/redteam.js` before the fix (red) and after (green).

## Reproduced, then fixed

- `javascript:` URLs in `session_url`, `html_url` and repo `url` rendered as live links.
  Red: 3 such hrefs in the DOM. Green: 0. Fix: `safeUrl` (https only) and `sessionUrl`
  (claude.ai only).
- Unknown status strings printed "undefined"; store documents with the wrong field types
  printed "[object Object]". Red: 2 occurrences. Green: 0. Fix: `txt`/`strs` scalar guards,
  label fallbacks, clamped priority.
- Alias and status lookups on plain objects threw for titles such as `constructor`.
  Fix: null-prototype maps and own-property checks for every untrusted key, including
  store document ids such as `__proto__`.

## Fixed from code reading

- One repo's GitHub error wiped GitHub data for every repo. Now scoped per repo and per feed;
  only connector-wide codes stop the layer, with a retry button.
- A repo with one feed failed and the other loaded read as "clean". Now "partial" until both
  feeds are present; "clean" wording replaced with what was checked.
- An authorisation error on the session feed emptied the page. Now the last good data stays
  with the notice.
- The empty inbox claimed "nothing is waiting" before handoff reports had loaded. Now
  qualified until the store answers.
- `needs_action` made a session critical for ever. Now ignored while the session is actively
  running, boilerplate ("none", "n/a") dropped, and downgraded to a warning after 14 days.
- Project matching by substring grouped unrelated titles. Now exact name, name followed by a
  space or hyphen, or a 4+ character title prefix.
- Every data event rebuilt the whole DOM. Now renders are debounced and a container is only
  rewritten when its HTML changed, so focus and selection survive refreshes.
- GitHub repo selection was by push date only. Now by attention (blocked sessions, waiting
  items) first; repos that drop out are unsubscribed; skipped lanes say "not checked".
- Pagination of sessions discarded page one when a later page failed and hid truncation.
  Now keeps what loaded, marks "newest only", and ignores out-of-order applies.
- Target dates compared in UTC flagged "overdue" on the due day. Now local calendar days.
- Escape discarded unsaved notes. Now warns when the editor is dirty.
- PR window widened from 30 to 100 so old merged PRs are less often missed.

## Not changed, by choice

- Whole-document `set` for notes. Single owner; a merge would add complexity for no gain yet.
- Stray-branch detection still cannot see a branch merged outside a pull request. Labelled.
- No author field on store documents: the store does not supply one.

## How to rerun

```bash
node tools/redteam.js page/overseer.html
OUT=/tmp node tools/shot.js page/overseer.html
```

Both need Playwright with Chromium. `redteam.js` prints `jsHrefs`, `protoPolluted`,
`undefinedText` and script errors; all should be zero or empty.
